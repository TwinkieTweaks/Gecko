# Gecko
Gecko is the Angelscript scripting engine used in [TwinkieX](https://github.com/TwinkieTweaks/TwinkieX) for writing Trackmania modules and modifications.
This repository represents the Microsoft Unit Testing Framework-based repository based upon Gecko. Gecko itself is available at https://github.com/TwinkieTweaks/Gecko/tree/development/Includes/Gecko

## More info
Some documentation is written in https://github.com/TwinkieTweaks/Gecko/blob/development/Includes/DOCS.md on the project structure and such.
